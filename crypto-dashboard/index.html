⚠️ Keine Anlageberatung. Alle Signale basieren auf frei verfügbaren technischen Indikatoren (RSI, MACD, gleitende Durchschnitte) und Kursdaten von CoinGecko. Sie sind rein informativ, können falsch liegen und ersetzen keine eigene Recherche oder Finanzberatung. Kryptowährungen sind hochvolatil – investiere nur, was du bereit bist zu verlieren.

CoinGecko verlangt inzwischen für jeden Zugriff einen kostenlosen Key. Erstelle einen "Demo API Key" unter coingecko.com/de/developers/dashboard (kein Zahlungsmittel nötig) und füge ihn oben ein – Key-Typ dabei auf "Demo" lassen, außer du hast bewusst einen bezahlten/Trial-Key erzeugt. Der Key wird nur lokal in deinem Browser gespeichert und ausschließlich direkt an CoinGecko gesendet.
